Place vendor JDBC drivers here for an image build, or set
`OPENMETADATA_EXTENSION_DRIVERS` to a directory containing the drivers.

Required files:

- `kingbase/kingbase8-8.6.0.jar`
- `dameng/DmJdbcDriver8.jar`
- `vastbase/Vastbase-G100-2.16_pg_2026062910.jar`

Driver JARs are intentionally excluded from Git because their redistribution
terms are vendor-controlled.
